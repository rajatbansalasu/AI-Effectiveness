Agent Control & MCP Architecture

Taming MCP & Tool Loops: Control Autonomous Agents

Model Context Protocol (MCP) connects Cursor to external tools (DBs, Git, Sentry, Terminal). But unguided multi-turn loops rapidly burn thousands of tokens in minutes.

1 User Intent
Prompt with goals, files, or bug description.
2 MCP Tool Invocation
Agent runs Postgres queries, Git diffs, or Bash commands.
3 Tool Output Ingestion
Entire terminal log / DB output appends into context.
4 The "Doom Loop" Risk
If tests fail, agent repeats loop → 50k to 300k+ tokens!

🛡️ The 4 Laws of Safe & High-ROI Agent Execution

Law 1
Pre-Curate Context (Never Let Agent Guess)

Pin exact file & line ranges: @OrderService.java:L45-80. Provide schema snippets rather than letting it search hundreds of files.

Law 2
Impose Strict Negative Constraints

State what NOT to touch: "Do not edit DB migrations, proto contracts, or pom.xml. Only patch OrderStatusHandler."

Law 3
Plan First, Gate Execution (Shift+Tab)

Ask for an architectural diff plan before running terminal bash commands or destructive multi-file overwrites.

Law 4
Beware the "MCP Schema Tax"

Every active MCP server registers tool schemas in your system prompt (5k–15k tokens/turn). Disable unused MCP servers in settings.

🎙️ Speaker Talking Points (5 mins):

  • What is MCP? Explain simply: Model Context Protocol (MCP) is the open standard that gives Cursor superpowers by letting the LLM talk to external systems—Postgres, GitHub, Jira, Sentry, Terminal, and file search.
  • Why do Unsteered Loops Explode? Walk through the 4-step diagram: The agent executes a tool (e.g. bash test run), ingests all 2,000 lines of terminal error logs back into context, tries to fix it by editing another file, tests again, and accumulates hundreds of thousands of tokens within 3 minutes.
  • Run the Interactive Demo: Click "Run Rogue Agent" to show the audience the simulated runaway loop ($7.25 burned, 32 files searched, build corrupted). Then click "Run Steered Agent" to demonstrate surgical precision (2,400 tokens, $0.03, tests green in 2.1s).
  • Explain Context Isolation (Subagents): Point to the bottom banner: When you need broad research or heavy terminal grep, use Cursor's Subagents (`cursor.com/docs/subagents`) so messy intermediate tool outputs don't contaminate your primary chat context.
  • Quote for the Room: "An unconstrained agent will happily spend 45 minutes refactoring your entire codebase to fix a typo. Steer the loop with negative constraints!"
