Appendix C • Workflow Velocity & Sandboxing

Power User Playbook: .cursorignore & Git Worktrees

Advanced hygiene to keep vector indexing clean, sandbox multi-file Agent refactors, and maximize developer velocity.

🛡️ Vector Indexing Hygiene: .cursorignore Root Config

Prevents 50k-line lockfiles and compiled binaries from polluting @codebase vector search: 

node_modules/
dist/ | build/ | target/ | .next/
coverage/ | .git/ | .env*
package-lock.json | yarn.lock | pnpm-lock.yaml
*.min.js | *.map | *.d.ts.map
🌲 Git Worktree Agent Sandboxing:
• Run autonomous multi-file refactors in an isolated worktree branch:
git worktree add ../ai-refactor -b refactor/order-service
• Protects your active dev server and uncommitted changes from dirty agent overwrites.

📋 Spec-Driven Development (SDD)

Phase 1 (Spec & Review): Ask Chat to write spec.md (contracts, endpoints, edge cases). Human reviews & approves.
Phase 2 (Surgical Execution): Prompt Composer: "Implement Step 1 from @spec.md only. Run tests before proceeding."

⚡ Velocity Shortcuts & Terminal Scoping

Cmd+K Inline 10-line edit
Option+Enter Fast non-indexed query
Cmd+Shift+L Send selection to Chat
Cmd+I Toggle Composer float
💡 Terminal Scoping: Pipe error logs using mvn test 2>&1 | tail -n 25 to prevent dumping 5,000 lines of buffer into context.

🎙️ Speaker Talking Points (3-4 mins):

  • The .cursorignore Imperative: Explain why lockfiles and build outputs are vector indexing poison: "When an engineer types @codebase how does auth work?, Cursor searches embeddings. If package-lock.json is indexed, it injects 30,000 lines of npm package names, crowding out actual source code!"
  • Git Worktree Sandboxing: Show how senior engineers run aggressive agent refactors in a separate git worktree without dirtying their main branch or killing their dev server.
  • Spec-Driven Development: Explain that writing a quick markdown spec before letting an agent touch code reduces wasted tokens and rollback cycles by over 70%.
