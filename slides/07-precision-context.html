Precision Context Referencing: @ Mastery

Stop typing @workspace. Learn the exact referencing symbols that feed the model pure signal.

@Files & Folders
Targeted Paths (Deep Drilldown)

Include exact files or directories: @auth.ts, @src/components/ (type / to navigate deeper).

@Terminals & Logs
Live Terminal Buffer

Pulls active terminal output and test failure traces directly into context without manual copy-pasting.

@Git (Diffs)
Working Changes or Branch Diffs

@Commit (Diff of Working State) for staged/uncommitted edits, or @Branch (Diff with Main) for PR reviews.

@Docs & Web
Official Framework Documentation

Indexes live external documentation (Spring Boot 3.3, Tailwind v4, Spark 3.5) to prevent API hallucination.

@Chats & Browser
Cross-Session & UI Context

@Chats references past architectural threads; @Browser inspects running web app DOM states.

🎯 Pro-Tip: Line Range Pinning
In Cursor, you can drag a line selection from your editor directly into the chat or reference @File.java:30-55 to only load 25 lines. This results in sub-second model responses!

🎙️ Speaker Talking Points (4 mins):

  • Explain why `@workspace` fails in large enterprise repos: Workspace indexing uses embeddings search. If you ask "fix authentication", embeddings might pull 20 random test files and config files rather than the specific JWT interceptor you care about.
  • Showcase `@Docs`: Tell engineers they can add custom docs in Cursor settings (e.g., internal company API docs, AWS CDK docs).
  • Mention `@Git`: "Before opening a PR, hit Cmd+L, type `@Git (Diff with Main) Review this PR for edge cases, memory leaks, and missing unit tests`. Instant 10x code review!"
