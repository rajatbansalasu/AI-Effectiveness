The Cursor Modality Playbook: Plan, Ask, Agent & Surfaces

Cursor provides 4 unified AI Chat Modes (cycle via Shift + Tab) alongside editor surfaces (Tab, Cmd+K). Picking the wrong mode burns 10x more tokens and causes file churn.

🗺️

Plan Mode

Shift+Tab • The Architect
Plan First 0 Diff Risk

Drafts implementation blueprint & file checklist before touching code.

Best For: Multi-file features, schema changes & large refactors.
💬

Ask Mode

Cmd+L • The Assistant
Read-Only Safe & Cheap

Conversational Q&A and syntax exploration with zero file mutations.

Best For: Legacy codebase onboarding, regex, and architecture Q&A.
🚀

Agent Mode

Cmd+I • The Builder
Autonomous Tool Loops

Autonomous multi-file editor: creates files, runs tests, and self-heals errors.

Best For: Executing approved plans, scaffolding & test suites.
🔬

Debug Mode

Shift+Tab • Investigator
Evidence-Based Log Inspector

Root-cause investigator that interrogates test failures without blind guessing.

Best For: Flaky tests, runtime race conditions & stack traces.
Engineering Task ❌ Inefficient Modality ✅ Optimal Modality & Surface Token & Speed Advantage
Quick 1-line null check or helper Open Agent / Composer (reads repo) Highlight → Cmd+K (Inline) or Tab 95% less tokens, < 1s instant diff
Understand 600-line legacy service Paste into Agent (accidental edits) Ask Mode (Cmd+L) with @file 100% read-only safe, 80% less tokens
Refactor 4 files & API contracts Run Agent blind without constraints Plan Mode first → approve → Agent Eliminates 100k token hallucination loops
Diagnose failing test or runtime error Ask generic chat with zero logs Debug Mode with @terminal logs Targeted surgical fix backed by evidence
💰 Docs Truth on Mode Pricing: All chat modes have identical per-token rates ($0 surcharge). Agent costs 10x–50x more purely due to multi-turn tool loops (reading files, executing bash, rewriting diffs).
💡 Keyboard Pro-Tip: Press Shift + Tab inside chat to instantly cycle Plan → Agent → Ask → Debug. Always Plan first, then execute with Agent!

🎙️ Speaker Talking Points (5 mins):

  • Chat Modes Pricing Clarification (Official Docs): Address the common executive/team question: "Does Agent mode cost more per token than Ask mode?" Official docs answer: No, the token rate is identical. However, the bill is 10x–50x higher because Agent mode autonomously chains 5–15 tool calls (reading entire files, running terminal tests, rewriting diffs).
  • The "Agent Trap": Explain why junior engineers get burned by defaulting to Agent mode for everything: "If you give Agent mode a vague prompt without planning, it will enthusiastically modify 8 files, install 2 npm packages, burn 200k tokens, and break your build in 30 seconds."
  • Why Plan Mode is Essential: Emphasize Plan mode as the senior developer's steering wheel. The AI acts as an architect, listing every file it plans to touch and its exact sequence of edits. You can refine or reject the strategy before any code changes occur.
  • Ask Mode for Safety: Highlight Ask mode as the safest way to navigate production repos or legacy systems. Because it is strictly read-only, there is zero risk of uncommitted diffs or accidental file deletions.
  • Don't Forget Cmd+K and Tab: For 80% of daily coding (small refactors, single functions, renaming), never open a chat window. Use Tab autocomplete (Tab) or Inline Edit (Cmd+K) to keep flow state intact.
