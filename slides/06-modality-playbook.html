The Cursor Modality Playbook: Plan, Ask, Agent & Surfaces

Cursor provides 4 unified AI Chat Modes (cycle via Shift + Tab) alongside editor surfaces (Tab, Cmd+K). Picking the wrong mode burns 10x more tokens and causes file churn.

🗺️

Plan Mode

Shift + Tab • The Architect
Plan First Zero File Risk

Drafts an implementation blueprint & dependency checklist for review before modifying code.

When to use: Multi-file features, major refactors, complex schema changes, and preventing destructive hallucinated file deletions.
💬

Ask Mode

Cmd + L • The Assistant
Read-Only Fast & Cheap

Conversational Q&A, syntax explanations, and codebase navigation with zero file mutations.

When to use: Exploring unfamiliar legacy files, explaining regex/algorithms, architecture debates, safe production inspection.
🚀

Agent Mode

Cmd + I • The Builder
Autonomous Multi-File Edits

Autonomous multi-file editor that creates files, runs terminal tests/lints, and self-heals syntax errors.

When to use: Executing an approved Plan, scaffolding fullstack features, cross-layer API contract sync, test verification.
🔬

Debug Mode

Shift + Tab • Investigator
Evidence-Based Log Inspector

Root-cause investigator that interrogates test failures, runtime errors, and logs without blind guessing.

When to use: Diagnosing flaky integration tests, race conditions, connection timeouts, and cryptic stack traces.

💰 Official Docs: Is there a Pricing Difference Between Chat Modes? Identical Token Rate • 10x-50x Token Volume
Per-Token Billing Rate: IDENTICAL ($0 Mode Surcharge)
Official Cursor docs confirm: there is no mode-specific surcharge. Plan, Ask, Agent, and Debug bill at the exact same base model token price (e.g., Sonnet 5 @ $2/$10 in/out with $0 platform markup).
Effective Cost: 10x–50x SPREAD (Tool Loop Overhead)
Ask Mode: 1 single Q&A turn = ~2k–5k tokens.
Agent Mode: Multi-turn tool execution loop (terminal runs, file reads, linter self-heals) = 50k–300k+ tokens per run!
💡 Workflow Pro-Tip: Press Shift + Tab inside the chat prompt to instantly toggle between Plan → Agent → Ask → Debug. For non-trivial features, always Plan first, review the file list, then hit Agent to execute! Shift + Tab = Quick Switch

🎙️ Speaker Talking Points (5 mins):

  • Chat Modes Pricing Clarification (Official Docs): Address the common executive/team question: "Does Agent mode cost more per token than Ask mode?" Official docs answer: No, the token rate is identical. However, the bill is 10x–50x higher because Agent mode autonomously chains 5–15 tool calls (reading entire files, running terminal tests, rewriting diffs).
  • The "Agent Trap": Explain why junior engineers get burned by defaulting to Agent mode for everything: "If you give Agent mode a vague prompt without planning, it will enthusiastically modify 8 files, install 2 npm packages, burn 200k tokens, and break your build in 30 seconds."
  • Why Plan Mode is Essential: Emphasize Plan mode as the senior developer's steering wheel. The AI acts as an architect, listing every file it plans to touch and its exact sequence of edits. You can refine or reject the strategy before any code changes occur.
  • Ask Mode for Safety: Highlight Ask mode as the safest way to navigate production repos or legacy systems. Because it is strictly read-only, there is zero risk of uncommitted diffs or accidental file deletions.
  • Don't Forget Cmd+K and Tab: For 80% of daily coding (small refactors, single functions, renaming), never open a chat window. Use Tab autocomplete (Tab) or Inline Edit (Cmd+K) to keep flow state intact.
