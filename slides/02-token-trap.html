The Problem

The Silent Productivity Killer: The 2M Token Trap

Why running an "infinite chat thread" is killing your code quality and multiplying latency.

❌ The Anti-Pattern: "Infinite Chat Syndrome"
  • Day-Long Chat Threads: Asking 20 unrelated questions in one Composer / Chat session without resetting.
  • Attention Dilution ("Lost in the Middle"): As context reaches 500k–2M tokens, the LLM's attention weights smear. Critical constraints are silently ignored.
  • Compounding Hallucinations: Bad code or temporary bugs produced at step 3 become "ground truth" context for step 15.
  • Latency Explosion: Model has to ingest 1.5M input tokens before generating 5 lines of code → 25s–40s delay per keystroke.
✅ The Fix: High-Velocity Ephemeral Context
  • The 3-Turn Rule: If the AI doesn't solve your bug or generate the correct code in 3 turns, do NOT argue with it. Hit Cmd+L / Cmd+N, prune your prompt, and start fresh.
  • Surgical Context Injection: Reference only the 2-3 files relevant to the current task using precise @file symbols.
  • Ephemeral Sessions: Treat chat threads like scratch buffers — disposable, single-purpose, and laser-focused.
  • Sub-2-Second Responses: Keeping context under 20k tokens yields instantaneous, razor-sharp generations.
