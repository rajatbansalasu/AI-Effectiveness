Appendix A • Infrastructure & Security

Team MCP Topology: Safe Multi-Developer Setup

How engineering teams deploy centralized, containerized MCP servers with strict token limits, read-only replicas, and secure credentials.

🏛️ Enterprise MCP Infrastructure Architecture

1. Developer Workstations (Cursor IDE)
Local .cursor/mcp.json points to secure corporate gateway via HTTPS / SSH tunnel.
⬇️ Passes Bearer Token & Query
2. Team Docker MCP Gateway (Rate-Limited & Truncated)
Enforces Max 50 Rows / 2,000 Tokens per query response to prevent context window explosion.
⬇️ Dispatches to Scoped Services
🐘 PostgreSQL MCP
Read-Only Replica only
⚡ Sentry Error MCP
Sanitized stack traces
🐙 GitHub PR MCP
Targeted branch diffs
📚 OpenAPI / Docs MCP
Live endpoint schemas
🚨 Security Rule #1: Never Grant Direct Write Access
Agents should only query read-only replicas. All schema mutations must go through reviewable Git migrations (Flyway / Liquibase).

📦 Production .cursor/mcp.json Blueprint JSON Config 

{
  "mcpServers": {
    "postgres-readonly": {
      "command": "docker",
      "args": [
        "run", "-i", "--rm",
        "-e", "DATABASE_URL=${POSTGRES_READONLY_URL}",
        "-e", "MAX_ROWS=50",
        "mcp/postgres:latest"
      ]
    },
    "sentry-issues": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sentry"],
      "env": {
        "SENTRY_AUTH_TOKEN": "${SENTRY_AUTH_TOKEN}"
      }
    }
  }
}
🛡️ The 3 MCP Enterprise Guardrails:
1. Row Limits: Hard-cap table returns to avoid 500k-token JSON bloat.
2. Env Secrets: Never commit plaintext tokens in mcp.json.
3. Context Isolation: Run heavy MCP exploratory queries in dedicated Subagents.

🎙️ Speaker Talking Points (3-4 mins):

  • Why Containerize MCP? Explain that if each developer runs ad-hoc MCP servers with local database credentials, you risk credentials leaking or engineers accidentally running mutating DDL queries on live databases.
  • The Token Truncation Rule: Highlight MAX_ROWS=50 in the Docker snippet. Explain: "If an agent queries a table with 100,000 rows without limit, it will attempt to feed 15MB of raw JSON into the context window, crashing the turn and burning your budget."
  • Credential Management: Emphasize using environment variables (${POSTGRES_READONLY_URL}) and read-only IAM roles.
