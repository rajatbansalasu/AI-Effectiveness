Starter .cursor/rules Templates Pack

Drop these .mdc files into your project's .cursor/rules/ directory:

---
description: Java Spring Boot API Standards
globs: src/main/java/**/*.java
alwaysApply: false
---
- Use Constructor Injection with `@RequiredArgsConstructor`. Never `@Autowired`.
- Controllers must return `ResponseEntity>`.
- Repositories must use Spring Data JPA specifications.
- Never use `java.util.Date`; always use `java.time.Instant` or `LocalDate`.
---
description: React & TypeScript UI Standards
globs: src/**/*.{tsx,ts}
alwaysApply: false
---
- Use functional components with explicit TypeScript prop types.
- Never use `any`; use `unknown` with Zod schema validation.
- Style exclusively with Tailwind CSS utility classes.
- Use `@tanstack/react-query` for all server data fetching.
---
description: Python & PySpark Pipeline Standards
globs: **/*.py
alwaysApply: false
---
- Use Python 3.11+ type hints (`typing.Annotated`, `pydantic`).
- Spark DataFrames must use Broadcast Join hints for small lookup tables (< 50MB).
- Never call `.collect()` on large datasets.
- Ensure idempotent writes with dynamic partition overwrite.
