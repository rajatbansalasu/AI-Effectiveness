🎯 3. Precision Context (@ Symbols)

  • @File.java:L20-50: Loads only 30 targeted lines (98% signal).
  • @Symbol / @Code: Pins specific class, interface, or method signature.
  • @Git (Diff with Main): Scopes review to branch changes & PR diffs.
  • @Docs: Indexes live official library docs (prevents stale API bugs).
  • @Folder: Restricts search boundary to 1 module or package.
  • 🚫 Avoid: Blind @workspace on large repos (loads 300k noisy tokens).

📝 4. The CCAO Prompt Framework

  • Context: Pin exact @file:Lxx-yy, symbols, and top 5 lines of stack trace.
  • Constraints: What NOT to touch, libraries to avoid, backwards-compat.
  • Action: Atomic verbs (Refactor, Extract, Optimize, Test, Scaffold).
  • Output: "Code diff only, zero conversational fluff, include regression test".

Universal Bugfix Formula:

Context: @Service.java:L40-80
Error: [Top 3 lines of stack trace]
Task: Fix the NullPointerException when payload is empty.
Constraints: DO NOT change method signature. Add JUnit 5 regression test.

📦 5. Starter .cursor/rules/*.mdc Blueprint

Place modular files in .cursor/rules/ scoped by glob patterns: 

---
description: Backend API Standards
globs: src/**/*.java
alwaysApply: false
---
- Use Constructor Injection (@RequiredArgsConstructor). Never @Autowired.
- Return ResponseEntity<ApiResponse<T>>.
- DO NOT use java.util.Date; use java.time.Instant.
- DO NOT swallow exceptions; wrap in domain ApiException.
- Write unit tests using JUnit 5 + AssertJ.
